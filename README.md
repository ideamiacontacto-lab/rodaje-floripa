# Rodaje Florianópolis · Estudio Ideamia

Sistema de producción para la cobertura audiovisual del viaje WhyNot (Astros Turismo) a Florianópolis, del 29/11 al 07/12/2026.

- Un panel por rol: Filmmaker, Fotógrafo · Híbrido o todo el equipo.
- Una pestaña por día con las tareas tildables, los ángulos de cada actividad, el equipo y lo que va al editor.
- Pestaña Info: calendario de Real-Time, rutina, seteo, estilo y pendientes.

Es un solo archivo, `index.html`. Fuera de claude.ai, las tareas tildadas y las notas se guardan solo en el navegador de cada persona (no se comparten entre dispositivos).
